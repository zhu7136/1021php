# Hu-D04 五教师学生策略：公开交付输入

本独立分支经用户明确许可公开发布教师、运行依赖及动作输入。主分支不修改。
**发布不是 GPU 启动许可；本分支不创建、提交或启动 Flux 任务。**

## 内容与完整性

- `inputs/`：核心包、训练动作、验证动作，共 810,521,059 字节，18 片。
- 每片最多 48 MiB；普通 Git blobs，不是 Git LFS 指针，不需要个人存储挂载。
- 清单包含每片及重组后完整文件的大小和 SHA-256。
- 独立清单 SHA-256：
  `5ab4bf8fc9b532e94f762a67c2968c26efa40f3a9f90bb6e9c378a9646101192`
- 核心包重打包清除了旧任务 ID、旧批准和聊天追踪标识；689 个非执行配置成员保持原字节。
- 训练和验证动作保持原文件哈希，未删减数据。
- 发布前全量重组/解包、23 项输入测试及 12 项工程范围回归检查通过。
- 未检出本次已授权的凭证值或常见私钥/签名链接格式；不包含限权输出 capability。

## 仅 CPU 校验

代码拉取后，在该仓库目录运行（输出目录必须不存在）：

```bash
python verify_inputs.py \
  --manifest-sha256 5ab4bf8fc9b532e94f762a67c2968c26efa40f3a9f90bb6e9c378a9646101192 \
  --output ./cpu-input-check
```

此命令不安装 wheel、不运行仿真、不启动训练，也不访问外部输入下载服务。
它只验证并重组文件到新目录。解包需要足够本地磁盘空间。

## Flux 接入边界

- 这是代码拉取后容器本地文件重组，不是 `personalDataPath` 挂载。
- 把较大输入放入代码仓库没有消除传输，Flux clone 时间及计费尚未验证。
- 本分支只提供待授权执行配置，`execution_approved=false`、`confirmed_by_user=false`、
  `task_id=null`。通用入口在调用工程 worker 前拒绝此配置。
- 下一次具体 GPU 试跑须单独确认次数、预算、时限、资源/镜像、输出交付和新任务绑定。
  不能仅修改输入哈希来冒充新任务已获授权。
- 旧工程建议范围是单卡、10 环境、100 更新、save25、worker 最长 1800 秒、自动重试 0。
  它不是本次发布附带的启动批准。
- Native shutdown、跨进程恢复和蒸馏质量仍需后续实测；不能把 CPU 校验当作训练成功。
