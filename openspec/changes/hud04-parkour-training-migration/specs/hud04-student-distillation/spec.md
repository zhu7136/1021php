## Purpose

把 HU_D04 的地形教师策略蒸馏为一个仅依赖本体感知与前视深度相机的学生策略，使机器人能在真实深度输入下自主选择合适步态完成越障与翻越。

## ADDED Requirements

### Requirement: 深度相机挂载与训练契约一致

HU_D04 的深度相机 MUST 挂载在躯干连杆上，MUST 使用 HU_D04 官方给出的安装外参（胸前相机 offset `(0.092, 0.0175, 0.4336)`，相对水平下俯 35°）。深度图 MUST 保持 58×87 的输入契约与 `[0.3, 3.0]` 的裁剪范围。

#### Scenario: 相机挂载在躯干
- **WHEN** 构建 HU_D04 深度相机
- **THEN** 相机父连杆为躯干连杆，且其外参与 HU_D04 官方描述一致

#### Scenario: 输入契约不变
- **WHEN** 深度图送入深度骨干网络
- **THEN** 图尺寸为 58×87，骨干输出的深度潜变量为 32 维

### Requirement: 支持单教师与多教师蒸馏

蒸馏 MUST 支持一个或多个教师，且 MUST 要求教师数量与数据集数量严格相等并按下标一一对应。数量不匹配时 MUST 明确报错而非静默运行。

#### Scenario: 单教师蒸馏
- **WHEN** 提供一个教师与一个数据集
- **THEN** 蒸馏正常启动

#### Scenario: 数量不匹配时报错
- **WHEN** 教师数量与数据集数量不相等
- **THEN** 训练拒绝启动并指出两侧数量

#### Scenario: 多教师顺序对应
- **WHEN** 提供多个教师与多个数据集
- **THEN** 每个教师按下标与对应数据集配对，且配对关系被打印记录

### Requirement: 学生观测包含深度潜变量

学生的观测 MUST 包含深度潜变量、本体感知与方向指令。缺失深度输入时 MUST 存在可运行的回退路径，且回退行为 MUST 被显式记录。

#### Scenario: 完整观测
- **WHEN** 深度输入可用
- **THEN** 学生观测包含 32 维深度潜变量与完整的本体感知项

#### Scenario: 无深度时回退
- **WHEN** 深度输入不可用
- **THEN** 学生在零填充深度下仍能运行，且该回退不改变观测维度

### Requirement: 蒸馏过程自动导出可部署产物

每次保存学生检查点时 MUST 同时导出可部署的 ONNX 组合（策略主体与深度骨干）。导出失败 MUST NOT 中断训练，但 MUST 产生可见的警告。

#### Scenario: 保存时导出
- **WHEN** 学生训练达到检查点保存间隔
- **THEN** 在同一迭代目录下生成学生策略 ONNX 与深度骨干 ONNX

#### Scenario: 导出失败可感知
- **WHEN** ONNX 导出发生错误
- **THEN** 训练继续，且错误信息以警告形式输出并指明迭代步
